Credit Card Default Prediction – ML Project

About
This project uses machine learning to predict whether a customer will default on their credit-card payment next month.

Target column: default payment next month
- 0 – No default
- 1 – Default
  
Tools Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook
  
Project Steps
1. Load the dataset.
2. Clean and prepare the data.
3. Handle missing values and duplicates.
4. Explore and visualize the data.
5. Split data into training and testing sets.
6. Select features.
7. Train classification models.
8. Evaluate model performance
   
Algorithms
- Logistic Regression
- Decision Tree
- Random Forest
  
Evaluation Metrics
- Accuracy, Precision, Recall, and F1-score.

How to Run
1. Keep the dataset CSV and notebook in the same folder.
2. Install the required libraries:pip install pandas numpy matplotlib seaborn scikit-learn jupyter
3. Open the notebook in Jupyter.
4. Run all cells in order.
   
Conclusion
This project demonstrates how machine learning can be used to predict credit-card payment defaults and compare different classification models.
